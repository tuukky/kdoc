# 검출률 측정 (정답 테스트셋)

공개 공고 문서에는 "정답 불일치 목록"이 없어서, **내역서에 불일치를 직접 심고** 도구가 찾아내는지 셉니다 ([PLAN_v1.md §3](PLAN_v1.md#3-정답-테스트셋-사전-등록)).

```powershell
python -m kdoc bench            # 전체 P1~P3, seed 42 → data/bench/results.json, results.md
python -m kdoc bench --seed 7 --per-type 5
```

## 방법

1. 각 공고의 시방서·내역서를 한 번 추출합니다. 원본 파일은 바꾸지 않습니다.
2. 추출한 내역서 항목 목록의 사본에 불일치 하나를 심고, 공정 짝(사용자 CSV + 이름 규칙, **AI 없음**) → 비교를 다시 돌립니다.
3. 심기 전 결과에 없던 의심 항목이 **정확한 자재·장/공종에** 새로 나오면 검출입니다. 관계없는 새 의심 항목은 부작용으로 따로 셉니다.
4. 유형별 후보를 모두 찾은 뒤 고정 시드로 뽑습니다 (프로젝트·유형당 최대 3건).

| 유형 | 심는 방법 | 검출 기준 |
|---|---|---|
| 자재 누락 | 짝 공종에서 시방서에도 있는 자재의 내역서 행을 지움 | `내역서에 없음` (공종이 통째로 비면 공정 짝 해제) |
| 자재 추가 | 같은 공사 다른 공종의 실제 행을, 그 자재가 시방서 짝 장에 없는 공종으로 옮김 | `시방서에 없음` |
| 수치 변경 | 시방서와 같은 단위 수치가 있는 내역서 행의 수치를 2배로 바꿈 | `수치 다름` |
| 공종 누락 | 짝이 있던 내역서 공종을 통째로 지움 | 해당 시방서 장이 `짝`이 아니게 됨 |

## 해석과 한계

- **수치 변경 0/7**: 실제 시방서·내역서에서는 한 줄에 여러 치수·부위가 섞이거나(`400*400*400(H), 우레탄방수1mm+코킹`), 시방서 수치가 범위·한계치(`~ 이상`)라 도구가 일부러 `판단 불가`로 둡니다. 7건 모두 해당 자재가 `판단 불가`로는 표시되지만, 이는 심기 전에도 표시되던 것이라 검출로 세지 않았습니다. 다음 개선 대상입니다.
- **자재 추가 100%**는 자재 사전에 있는 자재만 대상으로 한 결과입니다. 사전에 없는 자재는 원래 찾지 못합니다.
- 추출 이후 단계(공정 짝·비교)의 성능입니다. PDF·엑셀 추출 오류는 포함하지 않습니다.
- 후보가 적어(자재 누락 P1·P2 각 3개) 표본이 작습니다. 수치는 경향으로만 보십시오.
- **정밀도**(실제 공고에서 나온 의심 항목 중 진짜 문제 비율)와 **검토 시간**은 사람이 직접 판정해야 해서 별도로 측정합니다.

- 유형은 비교 기능이 실제로 내는 판정(`내역서에 없음`·`시방서에 없음`·`수치 다름`·공정 짝)에 맞춰 다시 정했습니다. 비교 기능(`compare.py`)에는 재질 대조와 수량 검사가 없어서, 재질 변경·단위·수량 이상을 심어도 잡을 수 있는 판정이 없습니다. 이 두 유형은 "측정하지 않음"이며 검출률 77%에 포함되지 않습니다.
- 두께 변경은 `수치 변경`(두께·횟수 등 숫자+단위)으로, 항목 삭제는 `자재 누락`으로 묶였습니다.
- 빠진 두 유형을 지금 추가로 재지 않습니다. 결과를 본 뒤 정답셋을 바꾸는 것과 같아지기 때문입니다. 필요하면 새 계획으로 다시 등록합니다 ([PLAN_v2.md §0](PLAN_v2.md#0-v1-정리-먼저-할-일)).
