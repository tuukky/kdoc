# 건설 문서 검토 보조 AI 프로젝트 Plan

## 1. 프로젝트 한 줄 정의

도면, 시방서, 내역서, 마감표, 창호표 등 건설 문서를 업로드하면  
문서 간 누락 가능성, 불일치 가능성, 검토 필요 항목을 자동으로 정리해주는 **건설 문서 검토 보조 AI**.

> 핵심 포지션: “AI가 오류를 보증하는 서비스”가 아니라 “공무/설계/감리 검토 시간을 줄여주는 보조 도구”

---

## 2. 왜 이 프로젝트인가?

### 해결하려는 문제

건설 실무에서는 다음 작업에 시간이 많이 든다.

- 도면과 내역서 비교
- 시방서와 내역서 비교
- 마감표와 평면도 비교
- 창호표와 내역서 비교
- 특기시방서 누락 확인
- 방수, 단열, 창호, 마감, 철물 등 주요 항목 검토

이 과정은 대부분 수작업이며, 실수하면 추가공사비, 분쟁, 공기 지연으로 이어질 수 있다.

### 고객이 돈을 낼 이유

고객은 “AI 문서검색”에 돈을 내는 것이 아니라,

- 검토 시간 단축
- 누락 가능성 조기 발견
- 반복 검토 업무 감소
- 실무자 피로도 감소
- 리스크 체크리스트 확보

에 돈을 낸다.

## 3. 대상 고객

### 1차 타깃

- 소규모 건축사무소
- 중소 시공사 공무팀
- 인테리어/리모델링 업체
- 현장 공무 담당자

### 2차 타깃

- CM사
- 감리업체
- 설계 검토 업체
- 하도급 업체

초기에는 대기업보다 소규모 업체가 적합하다.  
이유는 의사결정이 빠르고, 도구 도입 장벽이 낮기 때문이다.

## 4. 서비스가 하면 안 되는 말

법적 책임 리스크 때문에 아래 표현은 피한다.

- 오류를 완벽히 찾아드립니다
- 설계 오류를 보증합니다
- 문제 없음 판정
- AI가 최종 검토합니다
- 누락을 100% 방지합니다

---

## 5. 서비스가 해야 하는 말

아래 표현을 사용한다.

- 검토 시간을 줄여드립니다
- 누락 가능성을 제안합니다
- 문서 간 불일치 의심 항목을 정리합니다
- 최종 판단은 담당자가 수행합니다
- 검토 체크리스트를 자동 생성합니다
- 공무/설계 검토 보조 도구입니다

## 6. MVP 범위

처음부터 CAD 도면 전체를 AI가 이해하게 만들지 않는다.  
초기 MVP는 텍스트 기반 문서 비교에 집중한다.

### MVP 입력 문서

- PDF 시방서
- PDF 내역서
- PDF 마감표
- PDF 창호표
- PDF 도면에서 추출 가능한 문자 정보

### MVP 제외 범위

- CAD 직접 분석
- 도면 형상 인식
- 물량 자동 산출
- 구조 계산 검토
- 법적 책임이 필요한 최종 판단
- 100% 오류 검출 보증

### 기능 5. 검토 리포트 생성

결과를 사람이 확인하기 쉽게 정리한다.

리포트 예시:

```text
[검토 필요 항목]

1. 방수 항목 누락 가능성
- 시방서: 우레탄 방수 언급 있음
- 내역서: 방수 관련 항목 미발견
- 권장 조치: 내역서 방수 항목 포함 여부 확인

2. 단열재 두께 불일치 가능성
- 도면: THK100 단열재
- 내역서: THK80 단열재
- 권장 조치: 설계도서 기준 재확인

3. 창호 항목 검토 필요
- 창호표: AL창호
- 내역서: PVC창호
- 권장 조치: 창호 사양 일치 여부 확인
```

## 12. 법적 리스크 관리

### 필수 고지 문구

서비스 화면과 리포트에 아래 문구를 포함한다.

```text
본 서비스는 건설 문서 검토를 보조하기 위한 참고용 도구입니다.
AI 분석 결과는 최종 판단이 아니며, 실제 설계·시공·계약·정산 판단은 반드시 담당 전문가의 검토를 거쳐야 합니다.
본 서비스는 모든 오류, 누락, 불일치를 보증하지 않습니다.
```

### 제품 정책

- “문제 없음”이라는 표현 금지
- “검토 필요 항목 없음”으로 표현
- 최종 판단 책임은 사용자에게 있음을 명확히 표시
- AI 결과에는 항상 근거 문서와 페이지를 표시
- 심각도는 “확정”이 아니라 “의심 수준”으로 표시
