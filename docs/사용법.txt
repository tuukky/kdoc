kdoc — 시방서·내역서 검토 보조 프로그램 사용법

1. kdoc.exe 실행 (폴더 안의 다른 파일은 지우지 마세요)
2. 칸에 파일 넣기 — 끌어다 놓거나 [파일 찾기]
   - 시방서: PDF        - 내역서: 엑셀(xlsx, xls)        - 도면: PDF (이번 버전은 참고용, 비교 안 함)
3. (선택) [OpenAI 키 설정] — 키를 넣으면 이름이 다른 공정도 AI가 짝지어 줍니다.
   - 키는 윈도우 자격 증명 관리자에 저장되고, 프로그램·결과 파일에는 남지 않습니다.
   - AI에는 시방서 장·내역서 공종 '이름'만 보냅니다. 문서 본문은 보내지 않습니다.
   - 키가 없으면 이름이 같은 공정만 짝짓고 나머지는 '판단 불가'로 표시합니다.
4. [검토 시작] → 화면 표와 결과 엑셀(결과 폴더\검토_날짜시각\검토결과_….xlsx)
   - 공정 짝: 짝 / 판단 불가(노랑) / 없음(주황) + 근거
   - 시방서 → 내역서: 시방서 자재가 내역서 짝 공종에 없음, 두께·횟수 등 수치 다름
   - 내역서 → 시방서: 내역서 자재가 시방서 짝 장에 없음
5. 표의 줄을 더블클릭 → 원본 열기
   - 시방서 열을 누르면 브라우저(Edge/Chrome)로 해당 쪽, 내역서 열을 누르면 엑셀 파일(시트·행은 아래 상태줄에 안내)
   - 결과 엑셀의 '열기' 링크는 해당 쪽·시트·행으로 바로 이동합니다.

자재 사전: 이 폴더의 materials.txt
   - 여기 있는 자재만 찾습니다. 메모장으로 열어 한 줄에 하나씩 추가하세요.  예)  우레탄 방수: 우레탄, 폴리우레탄

주의: 결과는 문서 사이의 '의심 위치'입니다. 오류를 확정하지 않으며, 수정 여부는 설계자·협력업체 확인 후 판단하십시오.
